# Тест-зеркало: узнайте свои привычные стратегии

Одностраничный лендинг с интерактивным тестом-зеркалом. Пользователь проходит 16 вопросов, выбирая по одному варианту из шести (А–Е), и получает описание ведущей и второй привычной стратегии.

Это **тест-зеркало, а не диагностика**. Результат — повод для самонаблюдения, а не приговор.

## Стек

- **React + TypeScript** (Vite)
- **Tailwind CSS** — стилизация и адаптив
- **lucide-react** — иконки
- Без серверной части и без сторонних квиз-сервисов. Ответы хранятся только в `sessionStorage` браузера (без персональных данных) и сбрасываются по кнопке «Пройти заново».

## Запуск

```bash
npm install
npm run dev      # локальная разработка
npm run build    # продакшн-сборка

```


## Структура данных

### Вопросы
16 вопросов в `QUESTIONS`. У каждого — `id`, `text` и 6 вариантов в строгом порядке А, Б, В, Г, Д, Е. **Порядок вариантов не перемешивается** — ключ подсчёта привязан к буквам.

### Ключ подсчёта
`SCORING_KEY: Record<questionId, Record<letter, strategyKey>>`. Каждая буква ответа соответствует одной из шести стратегий:

- `avtonom` — Автоном
- `mayak` — Маяк
- `opora` — Опора
- `dvigatel` — Двигатель
- `estet` — Эстет
- `architector` — Архитектор

### Алгоритм
1. Инициализировать баллы всех шести стратегий нулями.
2. Для каждого ответа найти стратегию по `SCORING_KEY` и прибавить 1.
3. Всего 16 баллов.
4. Отсортировать по убыванию; при равенстве — фиксированный порядок: Автоном, Маяк, Опора, Двигатель, Эстет, Архитектор.
5. `top1`, `top2`, `top3` — первые три.
6. `mixed = (top1.score - top2.score) < 2` → заголовок «Ваш профиль — смешанный».
7. `flexible = (top1.score - top3.score) <= 2` → заголовок «У вас гибкий набор стратегий».
8. Если `top1.score == top2.score`, обе показываются как ведущие: для первой (по фиксированному порядку) — полное описание, для остальных — краткие блоки «Сильные стороны» и «Где сила начинает мешать».

### Результат
- Заголовок «Спасибо за прохождение теста».
- Текст с названиями top1 и top2 (без подстановки имени — персональные данные не собираются).
- Ведущая стратегия — полное описание по всем разделам.
- Вторая стратегия — разделы «Сильные стороны» и «Где сила начинает мешать» + пояснение «Когда основная стратегия не срабатывает, нередко включается вторая».
- При `mixed` и/или `flexible` — соответствующие заголовки.
- Пояснение об относительности баллов.
- Честный финальный блок и CTA-кнопка (ведёт на внешнюю ссылку, не обещает результат).
- Полный дисклеймер повторяется без сокращений.
- Сырые баллы в UI не выводятся (только `console.debug` для отладки).

## Приватность

- Имя, email и ответы **не отправляются на сервер**.
- Ответы хранятся в `sessionStorage` (ключ `mirror-test:answers`) без персональных данных; кнопка «Пройти заново» очищает их.
- Аналитика, передающая ответы или PII в третьи сервисы, не подключена.
- CTA ведёт на внешнюю форму/ссылку (настраивается в `CTA_CONFIG` в `src/data/content.ts`).

## Доступность

- Радио-варианты — настоящие `<input type="radio">` в `fieldset/legend`, работают с клавиатуры, видимый focus.
- Прогресс-бар с `aria-valuenow/aria-valuemin/aria-valuemax` и текстом «Вопрос X из 16». Не показывает 100%, пока не отвечены все 16.
- При переходе между вопросами фокус переходит на заголовок вопроса.
- Модалка «Важно знать»: focus trap, закрытие по Escape и кнопке, возврат фокуса.
- `prefers-reduced-motion` отключает анимации.
- Контраст текста и кнопок соответствует WCAG AA.
- Мобильная версия: крупные варианты, кнопки ≥ 44px, без горизонтального скролла.

## Настройка CTA

В `src/data/content.ts`:

```ts
export const CTA_CONFIG = {
  label: 'Записаться на консультацию',
  href: 'https://example.com/consult',
};
```

Можно заменить на «Присоединиться к практикуму» и нужную ссылку.
